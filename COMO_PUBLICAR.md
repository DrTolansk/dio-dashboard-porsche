# Publicar o projeto pelo celular

O repositório já criado para este trabalho é:

https://github.com/DrTolansk/dio-dashboard-porsche

## 1. Enviar os arquivos

1. Baixe o ZIP da entrega e extraia seu conteúdo no aplicativo de arquivos do Android.
2. Abra o repositório pelo Chrome, entrando na conta **DrTolansk**.
3. No repositório vazio, toque em **enviando um arquivo existente / uploading an existing file**. Se já houver arquivos, use **Add file → Upload files**.
4. Toque em **choose your files / escolha seus arquivos**.
5. Selecione os arquivos extraídos. Eles estão na mesma pasta para facilitar o envio pelo celular. O arquivo **index.html** deve ficar diretamente na raiz do repositório.
6. Aguarde o envio e confirme em **Commit changes / Confirmar alterações**. Uma mensagem possível para esse envio é: **Adicionar dashboard Porsche e documentação do projeto**.
7. Confira se a lista mostra index.html, README.md, as bases e as três imagens. Se o envio for dividido em etapas, complete os arquivos antes da entrega na DIO.

Use **index.html** como nome completo do painel. Se existir uma planilha de uma tentativa anterior, o dashboard web passa a ser aberto pelo index.html.

## 2. Ativar o GitHub Pages

1. Dentro do repositório, abra **Settings / Configurações**. No celular, essa opção pode estar dentro de **More / Mais**.
2. Encontre **Pages**, na seção de código, planejamento e automação.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch **main** e a pasta **/(root)**.
5. Toque em **Save / Salvar**.
6. Aguarde a publicação e confira o endereço apresentado pelo próprio GitHub.

O endereço esperado para essa conta e esse repositório é:

https://drtolansk.github.io/dio-dashboard-porsche/

Esse endereço só fica disponível depois que o envio e a ativação forem concluídos. O compartilhamento do Canvas mostrado na aula é uma forma adicional de visualização; a entrega deste projeto usa GitHub Pages.

## 3. Conferir a entrega

- Abra o endereço publicado.
- Selecione **Albuquerque**: devem aparecer **1 venda e $198,300**.
- Limpe os filtros e selecione pagamento **Cash**: devem aparecer **12 vendas e $1,326,550**.
- Limpe novamente: devem voltar **100 vendas e $12,827,801** no indicador arredondado.
- Confira se os prints do README abrem e se todos os arquivos citados existem.
- Atualize a descrição do repositório para: **Dashboard interativo de vendas da Porsche em HTML, CSS e JavaScript — projeto DIO.**
- Na DIO, envie o endereço do **repositório**: https://github.com/DrTolansk/dio-dashboard-porsche

Referência oficial: [Configurar a origem de publicação do GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
